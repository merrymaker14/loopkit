Resumen de LoopKit

LoopKit — referencia de API

Espacios de nombres: StrangeEuphoriaXR.LoopKit — núcleo C# independiente; .Unity — componentes y archivos; .Editor — diagnóstico y edición;.

using StrangeEuphoriaXR.LoopKit;

var loop = new LoopSession("courtyard-v1",
    new[] { new LoopCue("courier_leaves", 5, "courier", "leave", "gate") },
    new[] { new LoopFact("gate", "closed"), new LoopFact("code", "2417") });
loop.TryLearn(loop.Stamp, "player", "code", "2417",
    LoopLifetime.Persistent, "note", "Read the keeper's note.");
loop.AdvanceTo(6);
var reset = loop.BeginReset();
if (reset.Done && reset.Report.Succeeded) loop.Running = true;

Si el reinicio no termina inmediatamente, llama reset.Tick(unscaledRealSeconds) desde el juego hasta Done. LoopClockBehaviour ya lo hace.

API Contrato
LoopSession.SetSchedule Sustituye todo el horario con reloj parado, tiempo cero y sin trabajo pendiente; valida antes de modificar; conserva orden simultáneo; máximo 10000 eventos
ConfigureFacts Antes de comenzar, escribir, reiniciar o crear trabajo; máximo 10000 definiciones
Advance / AdvanceTo Tiempo finito no negativo, hasta 315360000 segundos; cada callback observa su límite exacto
Pause / Resume Identidad del objeto; cada propietario libera su propia pausa y un reinicio libera todas
Stamp / IsCurrent Identidad de sesión y generación creciente; no válido durante reinicio, fallo o tras Dispose
BeginWork Conserva el descriptor hasta que termine la tarea real o nativa, no solo la solicitud de cancelación
TrySetFact Estado explícito del mundo; no concede conocimiento
TryLearn Observador, valor observado, duración, fuente y causa; separado de la realidad
Knowledge.TryExplain Evidencia actual, fuente, causa, tiempo y generación de aprendizaje
TryRecordDecision Aceptación o rechazo y causa; no ejecuta una acción
Knowledge.Journal Últimos 512 registros; historial diagnóstico, no registro permanente ilimitado
Register(ILoopParticipant) ID único, cancelación, restauración y verificación; registrar antes del reinicio
Unregister(ILoopParticipant) Elimina inmediatamente fuera de un reinicio. Durante el reinicio mantiene su snapshot y aplaza la eliminación hasta finalizar, antes de ResetFinished, también si falla. Todavía pueden ejecutarse callbacks/esperas actuales; el participante destruido debe tolerarlos. No finaliza los leases de trabajo.
BeginReset Detiene, invalida, cancela, espera, restaura y verifica; timeout predeterminado de 10 segundos reales; no continúa automáticamente
CaptureCoreState Solo reloj, hechos y conocimientos; prohibido durante eventos o transiciones
RestoreCoreState Esquema, definición y huella coincidentes, prefijo válido de eventos; rechaza participantes del mundo
LoopCheckpointFile JSON hasta 4 MiB, reemplazo atómico en la misma carpeta y archivo anterior .bak
LoopRehearsal.Run Fábrica de sesión lógica nueva, acciones y expectativas explícitas; no simula la escena; un paso ExpectKnowledge con valor vacío acepta cualquier valor conocido

Se admiten 10000 pares observador/hecho, cada uno con memoria persistente previa y creencia temporal actual. Los ID no pueden estar vacíos, admiten hasta 160 caracteres y no permiten controles. Valores y causas admiten hasta 8192 caracteres. El límite de archivo puede alcanzarse antes: el guardado demasiado grande se rechaza sin reemplazar el anterior.

Las operaciones de sesión pertenecen al hilo creador. Solo LoopWork.Dispose admite otro hilo. Un sello de generación evita trabajo accidentalmente tardío, no es una frontera de seguridad frente al código del juego.

La integración MCP usa el API de Unity Pipeline 0.8.0-exp.1. Con otras versiones o sin Pipeline se excluye el adaptador; el núcleo sigue disponible. Conecta con unity mcp --project-path <ruta-absoluta>. Las cuatro herramientas loopkit_* solo leen; no hay servidor en Player.

Componentes y memoria permanente

API Contrato
CapturePersistentMemory Solo hechos y conocimientos permanentes; sin reloj ni estado de escena.
RestorePersistentMemory Valida/copia antes de modificar; cancela, espera, sustituye memoria y restaura/verifica participantes en tiempo cero.
LoopMemoryFile JSON hasta 4 MiB, sustitución atómica y .bak (nunca se carga solo); mismo esquema, ID de definición e ID de hechos permanentes. Los cambios del horario mantienen válida la memoria.
Revision / MemoryRevision Contadores para sincronización y guardado; leer no invoca callbacks.
LoopClockBehaviour.RememberAcrossRuns Carga/guardado con una casilla; MemoryPath relativa a persistentDataPath salvo rutas absolutas.
LoopClockBehaviour.RecoverMemoryFromCurrentSession() Recuperación explícita tras un error de persistencia y después de Start. Copia el archivo principal y .bak existentes a archivos únicos .recovery-<id> y guarda la memoria permanente actual. Devuelve false durante una carga/grupo de eventos o con una sesión inválida. Un fallo de archivo establece PersistenceError y mantiene desactivado el guardado automático; el éxito lo activa. No carga pistas antiguas, reinicia el mundo ni cambia el estado de ejecución.
LoopTimeSource GameTime por defecto; RealTime explícito. La espera de reinicio siempre es real.
LoopCueEvents.TryInvoke ID y LoopStamp original; rechaza generaciones antiguas. El grupo UnityEvent es síncrono.
RestartLoop / LoadMemoryFromEvent Métodos void para UnityEvent; transición al acabar el grupo. Gana la última solicitud. Dentro de un grupo, Restart() y LoadMemory() devuelven null porque la transición empieza después.
LoopKnowledgeGate Condición observador/hecho/valor, objetos y eventos; actualización tras sincronizar/cargar/reiniciar, incluso objetos inactivos.
LoopKnowledgeAction.Learn Conocimiento, duración, fuente y motivo desde Inspector; no modifica el mundo.
LoopFactAction.Apply Cambia hechos sin enseñar a observadores.
LoopTimedRoute Marcadores mundiales fijos capturados, tiempos crecientes e interpolación/pasos; participante de reinicio, sin evitar obstáculos.
LoopClockComponent.BindClock Llama tras asignar el reloj a un componente creado. Cambiar/quitar la vinculación durante el reinicio de cualquiera de las sesiones, o vincular una sesión destino fallida, lanza una excepción sin cambiar la vinculación anterior y restaura el campo clock. Reintenta tras la transición/recuperación. El Awake del reloj registra en la Console el componente que falla, con su objeto, y sigue con el resto.
LoopNavMeshRoute Ensamblado opcional Navigation 2.x; requiere NavMesh y agente. Guía a cualquier velocidad; la pausa detiene; saltos, cargas y reinicios hacen Warp; la verificación admite el ajuste al NavMesh dentro del radio del agente.
LoopClockBehaviour.RestartAndRun Acción void de UnityEvent: reinicia, espera la restauración/verificación correcta y ejecuta. Otro reinicio o carga cancela la solicitud anterior.

Requiere Unity 6000.5.7f1. La guía explica configuración, recuperación de archivos y ejemplo.
