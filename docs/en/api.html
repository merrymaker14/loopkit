LoopKit overview

LoopKit API reference

Namespaces: StrangeEuphoriaXR.LoopKit (engine-independent), .Unity (Unity hosts/files), .Editor (diagnostics and authoring).

using StrangeEuphoriaXR.LoopKit;

var loop = new LoopSession("courtyard-v1",
    new[] { new LoopCue("courier_leaves", 5, "courier", "leave", "gate") },
    new[] { new LoopFact("gate", "closed"), new LoopFact("code", "2417") });
loop.TryLearn(loop.Stamp, "player", "code", "2417",
    LoopLifetime.Persistent, "note", "Read the keeper's note.");
loop.AdvanceTo(6);
var reset = loop.BeginReset(); // immediate only when every registered operation has settled
// In a host update: if (!reset.Done) reset.Tick(unscaledRealSeconds);
if (reset.Done && reset.Report.Succeeded) loop.Running = true;
API Contract
LoopSession.SetSchedule Stopped at elapsed zero with no outstanding work or cue dispatch; validates a full replacement before mutation; stable ties; max 10000 cues
ConfigureFacts Before the first run, writes or reset, with no outstanding work; max 10000 definitions
Advance / AdvanceTo Nonnegative finite time, at most 315360000 seconds; callbacks observe each exact boundary
Pause / Resume Owner identity; every pause owner must release its own pause, and a reset clears all owners
Stamp / IsCurrent Session identity plus monotonically increasing generation; invalid while resetting/faulted/disposed
BeginWork Keep the lease until actual task/native settlement, not merely cancellation acknowledgement
TrySetFact Explicit world state; does not grant anyone knowledge
TryLearn Observer, observed value, scope, source and reason; distinct from truth
Knowledge.TryExplain Last current evidence, including source, reason and learned time/generation
TryRecordDecision Accepted/refused result and reason; does not execute a game action
Knowledge.Journal Last 512 chronological entries; diagnostic history, not an unlimited durable audit log
Register(ILoopParticipant) Unique participant ID, cancellation, restoration, verification; register before reset
Unregister(ILoopParticipant) Remove immediately outside a reset. During a reset, keep the active snapshot and defer removal until completion, before ResetFinished, including failure. Current callbacks/settlement may still run; destroyed participants must tolerate them. Removal does not settle work leases.
BeginReset Stops, invalidates, cancels, waits, restores, verifies; default timeout 10 real seconds; never resumes automatically
CaptureCoreState Only clock/facts/evidence; forbidden during cue dispatch or a transition
RestoreCoreState Exact schema/definition fingerprint and valid cue prefix; rejects sessions with world participants
LoopCheckpointFile JSON capped at 4 MiB; atomic same-directory file replacement and previous .bak
LoopRehearsal.Run Fresh logical session factory, explicit actions and assertions; no simulation of scene systems; an ExpectKnowledge step with an empty value accepts any known value

Observer/fact pairs are limited to 10000; both a persistent baseline and a temporary current belief can be stored for a pair. IDs are nonblank, at most 160 characters and contain no control characters. Value/reason fields are at most 8192 characters. The file-size limit can be reached before these per-field limits; oversized saves fail before replacing an existing file.

All mutable session operations belong to its creating thread. Only LoopWork.Dispose is safe from a worker thread. A generation stamp is not a security boundary against arbitrary game code; it rejects accidentally late work.

The MCP adapter targets Unity Pipeline 0.8.0-exp.1 and its Unity.Pipeline.Attributes API. Its assembly is excluded for other Pipeline versions or when Pipeline is absent; the core remains available. Connect with unity mcp --project-path <absolute-project-path>. Its four loopkit_* commands are read-only; the package contains no Player server.

Inspector components and durable memory

API Contract
CapturePersistentMemory Permanent world facts and persistent evidence baselines only; no clock/scene state.
RestorePersistentMemory Validate and deep-copy before mutation; cancel, settle, replace memory, restore/verify participants at time zero.
LoopMemoryFile 4 MiB bounded JSON, atomic replacement, previous .bak (never loaded automatically); same schema, definition ID and persistent fact IDs. Schedule changes keep memory valid.
Revision / MemoryRevision Change counters for host synchronization and durable saves; reading never invokes callbacks.
LoopClockBehaviour.RememberAcrossRuns One-checkbox automatic load/save; MemoryPath is relative to persistentDataPath unless absolute.
LoopClockBehaviour.RecoverMemoryFromCurrentSession() Explicit recovery after a persistence error and after Start. Copies existing primary and .bak files to unique .recovery-<id> files, then saves current permanent memory. Returns false during a load/designer event or for an invalid session. File failure sets PersistenceError and keeps automatic saving disabled; success enables it. Does not load old clues, reset the world or change running state.
LoopTimeSource GameTime by default; RealTime is explicit. Reset settlement uses real time in both modes.
LoopCueEvents.TryInvoke Cue ID plus original LoopStamp; rejects old generations. UnityEvent group is synchronous.
RestartLoop / LoadMemoryFromEvent Void UnityEvent entry points; transitions defer until the current group ends. Last transition request wins. Inside a group, Restart() and LoadMemory() return null because the transition starts afterwards.
LoopKnowledgeGate Observer/fact/value condition, object activation and events; refresh after synchronization/reset/load, including inactive targets.
LoopKnowledgeAction.Learn Inspector-authored evidence, lifetime, source and reason; world truth is unchanged.
LoopFactAction.Apply Set world truth without teaching observers.
LoopTimedRoute Captured stationary world-space markers, increasing times, step/interpolation; reset participant; no obstacle avoidance.
LoopClockComponent.BindClock Call after assigning a spawned view’s clock. Changing/removing a binding during either session’s reset, or binding to a faulted target, throws before changing the old binding and restores the clock field. Retry after the transition/recovery. The clock's own Awake logs a failing component with its object and continues with the rest.
LoopNavMeshRoute Optional Navigation 2.x assembly; baked NavMesh/agent required; steers at any clock speed; clock pauses stop motion; skips, loads and resets warp; reset verification allows the NavMesh-snapped start within the agent radius.
LoopClockBehaviour.RestartAndRun Void UnityEvent action: restart, wait for successful settlement/verification and run. A newer reset/load cancels this resume request.

Requires Unity 6000.5.7f1. See the guide for Inspector recipes, file failure recovery and the complete sample.
