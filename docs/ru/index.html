The Last Bell

Законченная загадка трёх петель, включённая в LoopKit. Скачать бесплатно для Windows на itch.io.

Построй петлю вокруг своей игры

Часы и расписание
События с UnityEvent, реальное или игровое время, пауза вместе с игрой и точная поза маршрута после перемотки.
Знания с источником
Одна галочка сохраняет постоянные улики между запусками игры. Управляйте объектами по знаниям наблюдателя, смотрите источник и причину каждой улики.
Проверяемый сброс
Отмени старую работу, дождись её завершения, восстанови участников и проверь остаточное состояние.

Откройте готовую сцену

Импортируйте .unitypackage в Assets либо установите поставку UPM и импортируйте The Last Bell через Package Manager → Samples.

В Unity 6000.5.7f1 с URP 17.5 откройте Prepared/TheLastBell.unity внутри папки примера и включите Play mode. В Prepared/Prefabs находятся 12 префабов моделей для повторного использования.

Для Built-in Render Pipeline выберите Tools → Strange Euphoria XR → LoopKit → Create last bell scene: генератор создаст сцену с материалами Standard. В URP генератор также доступен.

Ядро LoopKit от URP не зависит. Для своей петли добавьте часы, назначьте описание петли и подключите действия сцены в инспекторе.

Быстрый старт и руководство

В составе пакета

Настройка в инспекторе, таблицы с выбором наблюдателя, полные источники и причины, автоматическая постоянная память, маршруты Transform и две импортируемые головоломки. Tools, руководства и The Last Bell доступны на английском, русском, испанском и упрощённом китайском.

Требования и границы

Требуется Unity 6000.5.7f1. Постоянная память загружается в новую петлю, а не в произвольное сохранённое состояние сцены. Свои данные требуют участников. Уничтоженные объекты не воссоздаются автоматически. The Last Bell включает оригинальные модели Blender и четыре языка игры. A second chance — небольшой пример с примитивами.

Необязательные интеграции

Необязательные маршруты NavMesh используют Navigation 2.x. MCP только читает и рассчитан строго на Unity Pipeline 0.8.0-exp.1. При отсутствии подходящих пакетов эти сборки исключаются. Управляющего сервера в Player нет.
