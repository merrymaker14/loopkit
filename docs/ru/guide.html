Обзор LoopKit

Руководство LoopKit

Требуется Unity 6000.5.7f1. В пакете стандартные компоненты Unity, независимое ядро C# и два импортируемых примера. ИИ-модели и сетевой сервис не нужны. Интерфейс Tools и документация доступны на английском, русском, испанском и упрощённом китайском.

Начало в инспекторе

  1. Импортируйте пакет Asset Store через Package Manager → My Assets → Import либо локальный .unitypackage через Assets → Import Package → Custom Package. Для поставки UPM используйте Package Manager → Add package from disk (package.json) или Add package from tarball (.tgz).
  2. В Project создайте Strange Euphoria XR → LoopKit → Loop definition. Задайте стабильный уникальный ID, добавьте факты мира и события расписания.
  3. Добавьте в сцену LoopClockBehaviour и назначьте описание. Выберите начальные час/минуту, скорость и Игровое время. Включите Запустить при старте.
  4. Откройте Tools → Strange Euphoria XR → LoopKit → Workbench. Выбор языка также переводит инспекторы компонентов.

Поставка Asset Store размещается в Assets/StrangeEuphoriaXR/LoopKit; папки Documentation и Samples уже включены. В UPM руководства находятся в Documentation~, исходники примеров — в Samples~; пример сначала импортируется через Package Manager → Samples. Оставляйте в проекте одну установку LoopKit. Нужны стандартные модули Unity Audio, IMGUI, JSON serialization, Physics и UIElements; необязательные интеграции устанавливаются отдельно.

Память между запусками игры

Включите Помнить между запусками игры у часов. Одной галочки достаточно для автоматической загрузки и сохранения постоянных фактов и знаний наблюдателей. Относительный путь отсчитывается от Application.persistentDataPath; {definition} заменяется экранированным ID описания. Для разных игр, слотов и независимых часов назначайте разные файлы.

Знания выдаёт LoopKnowledgeAction: назначьте часы, наблюдателя player, ID факта, источник и причину; оставьте срок Между петлями и подключите Learn к кнопке, триггеру или событию. Чтение факта мира само по себе никого не обучает.

Загрузка начинает новую петлю с начала. Она отменяет старую работу, ждёт фактического завершения, заменяет постоянную память, восстанавливает зарегистрированных участников сцены и проверяет мир. Временные факты и знания очищаются. Временное противоречие не уничтожает постоянную исходную память. Наличие Reset Transform не мешает загрузке.

Автосохранение следует за постоянными изменениями и успешными сбросами; при паузе приложения и выходе инициализированная память также сохраняется. Размер JSON ограничен 4 МиБ, файл заменяется атомарно, прежний остаётся в .bak для ручного восстановления; сам LoopKit .bak не загружает. Должны совпадать схема, ID описания и набор ID постоянных фактов. Перенос, добавление и удаление событий расписания в обновлении игры сохранённую память не ломают; добавление, удаление или переименование постоянного факта требует нового пути памяти или собственного переноса. При включённой автоматической памяти некорректный стартовый файл или загрузка, которая начала сброс, но не прошла ожидание/проверку, оставляют автосохранение отключённым, а Запустить при старте не запускает часы: что предложить игроку, решает игра. Ручная загрузка, отклонённая до перехода — например, из-за некорректного JSON или другого отпечатка, — сохраняет действующую сессию: её автосохранение продолжается по выбранному пути и после постоянного изменения может заменить этот файл. Технические подробности видны в инспекторе часов. Перед продолжением сохраните файл и выберите верный путь/описание либо явно перенесённый или новый слот. Файловое хранение проверено на Windows; это не облачная синхронизация и не снимок произвольной сцены.

Чтобы продолжить с уже найденными в текущей сессии уликами, после ошибки памяти явно вызовите LoopClockBehaviour.RecoverMemoryFromCurrentSession(). Метод сначала копирует существующие основной файл и .bak в отдельные файлы с окончанием .recovery-<unique-id> рядом с сохранением. Только после успешного копирования обоих файлов он атомарно записывает текущие постоянные факты и улики; старые улики не загружаются. Готовые резервные копии не заменяются, в том числе при повторной попытке. Ошибка копирования или записи возвращает false, задаёт PersistenceError и оставляет автосохранение отключённым; текущие улики остаются в памяти. Требуются завершённый Start и исправная сессия вне загрузки или группы событий инспектора. Метод не сбрасывает, не перематывает и не запускает петлю. При неисправной сессии сначала устраните причину и успешно выполните сброс. The Last Bell показывает ошибку и кнопку восстановления в стартовом меню и меню паузы. Выбирайте это действие, когда хотите сделать текущие улики новым сохранением; прежние файлы остаются в отдельных резервных копиях.

В 21:30 открыть дверь

Добавьте событие в описание, задайте ID, например open_door, включите Задать время суток и укажите 21:30. На активный объект сцены добавьте LoopCueEvents, выберите те же часы, создайте реакцию с этим ID и подключите UnityEvent к GameObject.SetActive(false) двери. Двери добавьте LoopResetTransform с теми же часами и уникальным ID участника.

События вызываются по одному разу за петлю в устойчивом порядке. Секунды отсчитываются от начала петли; более раннее время суток означает следующие сутки. ID и значения автора не переводятся. Отложенный вызов должен хранить исходную отметку поколения. Каждая группа UnityEvent синхронна; RestartLoop, RestartAndRun и LoadMemoryFromEvent часов откладывают переход до возврата группы. Последний запрос перехода в группе имеет приоритет. Код, напрямую вызывающий переход сессии, сам координирует границы обработчиков.

Показать кнопку, когда игрок знает код

Добавьте LoopKnowledgeGate, наблюдателя player и ID факта с кодом. Назначьте кнопку в Включать, когда известно; при необходимости задайте точное значение, объекты/события неизвестного состояния. Пересчёт происходит при синхронизации часов/в конце кадра после обучения, загрузки и сброса. Часы могут включить даже собственный неактивный объект переключателя. Держите часы вне управляемых объектов. Отключение самого компонента останавливает пересчёт. Объекты из сцены, загруженной позже часов, должны быть активны при её загрузке; иначе вызовите BindClock() (для Reset Transform — RegisterInitialState()) сами.

Эмма в 22:00 идёт на кухню

Добавьте LoopTimedRoute, уникальный ID и Transform персонажа. Создайте неподвижные маркеры назначения вне иерархии персонажа. Добавьте точки в строго возрастающем порядке: секунды или ЧЧ:ММ. Выберите плавное движение либо переход в заданный момент. Мировые позы маркеров фиксируются при подключении. Advance/AdvanceTo часов сразу ставят персонажа в точную позу расписания, в том числе при короткой перемотке.

Маршрут сам восстанавливает исходную позу и проверяет её при сбросе. Не добавляйте тому же персонажу Reset Transform: конфликт владельцев диагностируется. Transform-маршрут не обходит стены. Для созданного во время игры маршрута назначьте поля и вызовите BindClock() до изменения персонажа. Инвентарь, анимация, изменение родителя/масштаба и воссоздание уничтоженных объектов требуют собственного участника.

LoopNavMeshRoute включается отдельной сборкой только при наличии com.unity.ai.navigation 2.x. Назначьте NavMeshAgent и подготовьте подходящий NavMesh. При обычном ходе времени на любой скорости агент идёт сам; он останавливается вместе с часами, а при перемотке, загрузке и сбросе переносится в заданную позу. Проверка сброса принимает стартовую точку, к которой агент притянулся на NavMesh, в пределах его радиуса. Поза вне NavMesh проваливает сброс и выводится в Console. Маркеры должны лежать на запечённой поверхности. Основной пакет не устанавливает Navigation.

Пауза и объяснение событий

Игровое время использует Time.deltaTime: Time.timeScale = 0 останавливает часы. Реальное время намеренно не зависит от timeScale. Скорость — секунды петли за секунду выбранного источника. Ожидание сброса всегда измеряется реальным временем. Ручная перемотка явная и может двигать остановленные часы. В коде также доступны независимые Pause(owner)/Resume(owner).

Workbench показывает знания выбранного наблюдателя рядом с журналом причин. Выберите строку, чтобы прочитать полный источник, причину, срок и время. В расписании отмечено выполненное и предстоящее, в фактах мира — реальные значения. Персонаж может знать ошибочные или устаревшие сведения: знание не равно истине. Проверка сброса показывает конкретные проблемы участников. Журнал хранит последние 512 записей и не является бесконечным сохраняемым аудитом. Если компонент выбрасывает исключение при привязке или обновлении, LoopKit записывает его в Console вместе с объектом и продолжает обновлять остальные; ошибка обновления выводится один раз за петлю.

Примеры

Для UPM импортируйте The Last Bell через Package Manager → Samples. В поставке Asset Store пример уже включён. В проекте URP 17.5 на Unity 6000.5.7f1 откройте Prepared/TheLastBell.unity внутри папки примера и включите Play mode. В поставке Asset Store путь — Assets/StrangeEuphoriaXR/LoopKit/Samples/LastBell/Prepared/TheLastBell.unity; после импорта UPM — папка Assets/Samples/LoopKit/1.0.0/The Last Bell/Prepared. В Prepared/Prefabs находятся 12 префабов моделей для повторного использования. Готовая сцена и материалы требуют URP; ядро LoopKit от URP не зависит. Для Built-in Render Pipeline выберите Tools → Strange Euphoria XR → LoopKit → Create last bell scene: генератор создаст сцену с материалами Standard. В URP генератор также доступен.

WASD/стрелки — идти, E — действие, Tab — улики, Esc — пауза. Законченная загадка требует трёх петель: узнать код шкафчика; взять предохранитель и прочитать инструкцию; применить запомненный порядок сигналов заранее и предупредить курьера. Меню, улики и финал доступны на четырёх языках. Знания сохраняются после перезапуска Player, физические предметы — нет. В сцену входят оригинальные модели Blender: станция, поезд, двор, персонажи и предметы загадки. Другие плагины и модели ИИ не требуются.

A second chance — небольшой второй пример с английским игровым интерфейсом: прочитайте 2417 после шестой секунды, сбросьте мир и откройте ворота до ухода курьера на пятой.

Ядро, свои системы и MCP

CaptureCoreState/RestoreCoreState сохраняют часы, префикс выполненных событий, факты и знания. Загрузка только ядра намеренно отказывает при участниках мира. Для постоянных знаний с исходным миром используйте CapturePersistentMemory/RestorePersistentMemory. Обе загрузки валидируют данные до изменения сессии и инвалидируют старые операции. Удерживайте LoopWork до реального завершения работы. Ошибка восстановления оставляет мир остановленным; исправьте причину и повторите сброс. Сессию изменяет создавший её поток; только LoopWork.Dispose можно вызывать с рабочего потока.

LoopRehearsal.Run проверяет логические ветви, а не физику, изображение или навигацию. MCP рассчитан строго на Unity Pipeline 0.8.0-exp.1. Подключение: unity mcp --project-path <полный-путь-проекта>. Команды loopkit_status, loopkit_schedule, loopkit_knowledge, loopkit_reset_report только читают явно выбранные часы/наблюдателя. При другой версии адаптер исключается. Управляющего сервера в Player нет.

Автоматически повторять петлю

Для автоматической петли подключите последнее событие расписания к LoopClockBehaviour → RestartAndRun. Часы продолжатся после отмены старой работы, ожидания и успешной проверки сброса. RestartLoop сбрасывает и останавливает часы. Неуспешный или заменённый новым запросом сброс не запускает время. В Workbench и инспекторе работающих часов доступна та же команда Сбросить и запустить. События видят Transform-маршруты в точной позиции своей временной границы, в том числе при перемотке. NavMesh-маршруты используют обычное движение агента на тиках и перенос при явной перемотке/сбросе; при обычной навигации прибытие к границе события не гарантируется. Изменённая постоянная память сохраняется и при уничтожении активных часов, если сессия готова и исправна.

Версия 1.0.0

Включает действия и условия по знанию в инспекторе, постоянную память, маршруты по времени, проверку сброса и диагностику MCP только для чтения в редакторе. The Last Bell — загадка трёх петель с 12 оригинальными FBX-моделями; A second chance — небольшой пример. Инструменты редактора, руководства, справочник API и The Last Bell поддерживают английский, русский, испанский и упрощённый китайский.

Состав пакета и лицензии

Пакет содержит исходный код, шейдеры, графику продукта, документацию и ресурсы примеров. В The Last Bell включён «Autumn Clues» — предоставленный издателем трек, созданный с Suno и подготовленный для циклического воспроизведения; громкость регулируется в меню примера. Стандартные модули Unity Engine объявлены в manifest. Navigation и Unity Pipeline — отдельные необязательные зависимости. В The Last Bell включён шрифт Noto Sans CJK SC по лицензии SIL Open Font License 1.1 (см. Third-party notices). Сторонние библиотеки кода и веса ИИ-моделей в пакет не включены.
