The Last Bell

体验 LoopKit 附带的完整三循环谜题。在 itch.io 免费下载 Windows 版。

围绕你的游戏构建循环

时钟与日程
使用 UnityEvent 配置事件，选择真实或游戏时间，随游戏暂停，并在时间跳转后设置精确路线姿态。
有来源的知识
一个复选框即可跨游戏启动保存永久线索。按观察者知识控制对象，查看每条线索的来源与原因。
可验证的重置
取消旧操作，等待实际结束，恢复参与对象，并检查残留状态。

打开附带的场景

将 .unitypackage 导入 Assets，或安装 UPM 版本并通过 Package Manager → Samples 导入 The Last Bell。

在 Unity 6000.5.7f1 的 URP 17.5 项目中，打开示例文件夹内的 Prepared/TheLastBell.unity，然后进入 Play mode。Prepared/Prefabs 包含 12 个可复用的模型预制件。

使用 Built-in Render Pipeline 时，选择 Tools → Strange Euphoria XR → LoopKit → Create last bell scene，生成使用 Standard 材质的场景。URP 项目也可使用此生成器。

LoopKit 核心不依赖 URP。添加时钟、指定循环定义，并在 Inspector 中连接场景操作，即可构建自己的循环。

快速入门与指南

包内内容

Inspector 配置、观察者筛选表格、完整来源与原因、自动永久记忆、Transform 路线以及两个可导入谜题。Tools、指南和 The Last Bell 支持英语、俄语、西班牙语与简体中文。

要求与边界

需要 Unity 6000.5.7f1。永久记忆在新循环中读取，不是任意场景存档。自定义数据需要参与对象；已销毁对象不会自动重建。The Last Bell 包含原创 Blender 美术及四种游戏语言。A second chance 是使用基元的小型示例。

可选集成

可选 NavMesh 路线使用 Navigation 2.x。只读 MCP 精确支持 Unity Pipeline 0.8.0-exp.1。缺少对应包时排除相关程序集。Player 中不包含控制服务器。
